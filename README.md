# LexiQuest 英语单词闯关

一个面向中小学生的英语词汇闯关网页。项目无需安装依赖，浏览器即可运行，适合作为 AI Coding、青少年编程教学和前端交互设计的演示项目。

## 功能

- 小学、初中、高中三级词库
- 看英文选中文、看中文选英文、中英混合三种模式
- 浏览器英文发音
- 连续答对加分与提示扣分
- 错词自动收集与集中重练
- 本局学习报告
- 使用浏览器本地存储保留累计数据
- 支持键盘数字键和 Enter 快速操作
- 适配手机与电脑

## 本地运行

### 方法一：直接打开

双击 `dist/index.html` 即可运行。

### 方法二：启动本地服务器

在项目目录打开 PowerShell：

```powershell
python -m http.server 8000 --directory dist
```

然后浏览器访问：

```text
http://localhost:8000
```

按 `Ctrl + C` 可以停止服务器。

## 面试介绍参考

我使用 AI Coding 辅助完成了一个面向中小学生的英语单词闯关项目。我先把需求拆分为难度选择、随机出题、答题判定、计分、错词复习和学习报告等模块，再逐步生成并检查代码。项目使用原生 HTML、CSS 和 JavaScript 实现，不依赖复杂框架，可以直接在本地运行。数据通过浏览器 localStorage 保存，并使用 Web Speech API 实现单词发音。我重点负责功能设计、提示词编写、代码整合、测试以及移动端界面调整。
